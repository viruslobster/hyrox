# Requirements
- 3 different types of running per week
    - 1-2 slow long runs
    - 1 interval speed work
    - compromised running (HYROX set)
- 2-3 strength sessions per week
    - mostly compound
    - mix of strength lower reps and muscular endurance
    - can combine with intervals runs
- 3 hyrox sessions per week
- 2 workouts that end with 100 wall balls per week
- Every hyrox workout done at least once per week 

# Workout split

| Day | Focus | Example workout |
| --- | --- | --- |
| Monday | Rest / optional aerobic volume | Rest or another long run |
| Tuesday | Lower body strength + compromised running | Leg press then 5x500m run + 50 wall balls |
| Wednesday | Upper body strength + HYROX ergs | Bench, row, then 5x1000m SkiErg + sled push |
| Thursday | Rest | Rest |
| Friday | Interval running + HYROX run/erg | Progressive run: 4x800m @ 70%, 80%, 90%, 100% (no rest), then 5x500 run + lunges
| Saturday | Misc strength + HYROX ergs OR double HYROX set | RDL and shoulder press, then 5x500m row + burpee broad jumps |
| Sunday | Long run | Long run |

- 1km run

- 1km run
- 1000m RowErg
- 1km run

- 1km run

- 1km run
